# Personal Expense Tracker

A private, client-side expense tracker built with HTML, CSS and JavaScript.

## Features
- Dashboard with income, expenses, balance and savings rate
- Add, edit and delete transactions
- Categories and payment methods
- Monthly filtering
- Search and filters
- Expense/category charts
- Monthly income vs expense chart
- CSV export
- JSON backup and restore
- Light/dark mode
- Responsive design
- Browser localStorage — no backend required

## Run locally
Open `index.html` in a modern browser.

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide your Pages URL.

## Privacy
Transactions are stored in the browser's localStorage. They are not uploaded to GitHub by this application.

For cross-device synchronization, a future version can use Firebase, Supabase or Google Sheets.
